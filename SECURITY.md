# Security Policy

## Supported Versions

This is an initial public reference project. Security reports should target the latest version on the default branch.

## Reporting a Vulnerability

Please open a private security advisory if hosted on GitHub, or contact the maintainer directly.

Do not include real credentials, internal hostnames, private logs, customer data, access tokens, or regulated records in public reports.

## Defensive Scope

InfraSentinel is designed for anomaly detection, alert enrichment, and response guidance. It intentionally excludes offensive security automation and exploit behavior.
