# Data Card

## Dataset

InfraSentinel uses synthetic server telemetry generated by `infrasentinel_ai.data.synthetic`.

## Why Synthetic Data

Synthetic data makes the repository safe to publish while preserving a realistic engineering workflow:

- No credentials.
- No internal hostnames.
- No customer logs.
- No exploit traces.
- Reproducible behavior for tests and demos.

## Columns

- `host_id`
- `cpu_percent`
- `memory_percent`
- `failed_ssh_logins`
- `successful_ssh_logins`
- `sudo_commands`
- `new_user_created`
- `process_count`
- `outbound_connections`
- `bytes_out_mb`
- `listening_ports`
- `package_install_count`
- `hour_of_day`
- `is_weekend`
- `is_security_anomaly`

## Governance Notes

Production use must define retention, access control, privacy review, and approval for every telemetry source. Sensitive logs should be tokenized or minimized before analytics workflows.
